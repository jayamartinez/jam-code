JAM Code is a free, open-source, local-first desktop workspace for coding
agents. This is the first public **alpha**, for technical early adopters: it
works, it will have rough edges, and it may change in incompatible ways.

## What's in it

- **Projects from folders.** Open any folder with the system folder picker;
  Git is optional. Remove a project from JAM without touching its files.
- **Claude Code and Codex chats** through the CLIs you already installed and
  signed in to (`claude` stream-json and `codex app-server`), with streaming,
  approvals, questions, interrupt and resume, model and effort choices, and
  context usage. JAM Code never reads or stores your credentials.
- **Worktree chats.** Start a chat in the current checkout or in a new Git
  worktree on its own branch, so parallel chats never edit the same files.
- **Searchable local history** in SQLite with full-text search.
- **Terminal** (a real shell in a PTY), **Browser** (the system web view, with
  element and region annotations you can stage into a chat), a read-only
  **file browser and editor**, and **Review** of Git changes with stage and
  unstage.
- **Tabs and tiles**: any resource in any pane.
- **Appearance**: themes, accents, fonts, backgrounds.
- **Snapshots** (macOS 14+): capture a window into a chat's composer.

## Before you install

- **Windows 11 x64** and **macOS 14+** (one universal build for Apple silicon and
  Intel). Windows 10 and Intel Macs are untested.
- Install [Claude Code](https://docs.anthropic.com/en/docs/claude-code) and/or
  [Codex](https://github.com/openai/codex) and sign in with their own CLIs.
  JAM Code works with either one, both, or neither (then you can still use
  projects, terminals, the browser, files and Review).
- Whether a Claude subscription may be used through a third-party app is
  unresolved; JAM Code runs the unmodified `claude` CLI with its own sign-in.
  See `docs/PROVIDERS.md`.

## Unsigned builds

These installers are not code-signed.

- **Windows:** SmartScreen will warn. Choose _More info → Run anyway_.
- **macOS:** the app is not notarized. Right-click the app → _Open_, or run
  `xattr -dr com.apple.quarantine "/Applications/JAM Code.app"`.

Verify downloads against `SHA256SUMS.txt`.

## Known limitations

- Files open read-only; agents edit files, JAM Code does not yet.
- No automatic updates, no history import from the providers' own apps, no
  remote access, no JAM account.
- Snapshots are macOS-only. Browser is a prototype without devtools.
- Quit interrupts running chats (they can be resumed).
- Developed on Windows 11 and macOS 15; other versions are untested.

## Upgrading from a development build

On first launch JAM Code copies the old `jam-demo.sqlite` to `jam.sqlite`,
removes the sample projects and chats, and keeps your own projects, chats and
settings. The old file is left untouched.
